# QuizVerse

QuizVerse is an interactive quiz application designed to provide users with an engaging and user-friendly quiz experience.

## Features

- User-friendly quiz interface
- Multiple-choice questions
- Score calculation
- Interactive quiz experience
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
